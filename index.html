The problem
Financial news moves fast and is full of noise — duplicate headlines, ads, and low-signal commentary. This workflow filters it down to what matters: deduplicating by semantic similarity, dropping irrelevant content via a blacklist, scoring each remaining headline with a local LLM, and delivering only the highest-signal stories as rich messages.

{}

GitHub repo›
Key decisions
Why local LLM?
No API costs, no rate limits, runs offline. Ollama makes local inference straightforward.
Jaccard similarity
Lightweight and effective for headline dedup — no embeddings needed for this use case.
Price bucketing
Groups stocks by price range so the digest is scannable — high-priced and penny stocks don't compete for attention.
